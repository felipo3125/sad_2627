## 3. IP spoofing

### Qué es
vulnerabilidad activa que pillas las credenciales aprovechando fallos de seguridad 

### Cómo se lleva a cabo
se ejecuta principalmente con herramientas capturas de usuarios y contraseñas

herramientas de trafico de red como sniffers, tencicas como phishing(engaño), 

### Qué categoría(s) de amenaza compromete

compromete 
cuando se capturan datos en una transmision mediante punto A y B, se roban esos datos que se estan trasmitiendo para usar esa informacion a su favor

### Ejemplo o caso real
julio de 2025 que se considera mayor exposiion de datos.
30 conjunto de datos que sumaban 16 millones de registros con nombre de usuario y contraseñas...
### Medida de prevención
usar contraseñas seguras y diferentes para diferentes cuentas como google, gmail, facebook.... y junto con 2FA para evitarlo
